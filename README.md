# retracted

Two language models debate a motion while Jev, TypeSafe's typed decision model, checks every finished sentence against a shared evidence pack. A factual claim the evidence does not support is struck through on screen while the next sentence is still arriving. Run headless across many models, the same engine produces a leaderboard of which model gets retracted least.

Jev never generates text. It answers typed questions (yes/no probability, choice, score) over a state, at roughly 110 to 270 ms per request and $0.042 per million input tokens, with output free. That is cheap and fast enough to judge every sentence at the speed of streaming.

Status: scaffold only. Sections are added as the parts they describe work.
